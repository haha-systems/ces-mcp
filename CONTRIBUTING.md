# Contributing

Use Go 1.26 or newer. Run the build and checks listed in [`docs/DEVELOPMENT.md`](docs/DEVELOPMENT.md) before opening a pull request.

For changes to CES state or phase rules, read [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md). For changes to MCP tools, resources, or schemas, update [`docs/MCP_API.md`](docs/MCP_API.md) and the matching tests.
